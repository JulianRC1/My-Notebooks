# My Notebooks

This repository brings together a collection of notebooks and projects developed throughout my university studies in Computer Science. It serves as a personal archive of my academic work and documents my learning process across different areas of computing and artificial intelligence.

The repository includes projects covering topics such as **Machine Learning, Deep Learning, Natural Language Processing (NLP), Recurrent Neural Networks (RNNs), Transformers, Named Entity Recognition (NER), and Large Language Models (LLMs)**.

Each notebook focuses on a specific problem or concept and includes the corresponding implementation, experimentation, evaluation, and analysis of the results.

The goal of this repository is to showcase my academic experience, practical skills, and progression in the development and application of AI and machine learning techniques.
